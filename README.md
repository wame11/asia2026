# 🗾 Asia 2026

Japan &amp; South Korea — Ross Family, 16–31 October 2026.

A single-page website holding the whole trip plan: an overview in seven points,
a day-by-day summary with everything explained in brackets, and the full
itinerary — all in collapsible sections so nothing is one long wall of text.

**The site is `index.html`.** No build step, no dependencies — open it in any
browser, or serve the folder.

## Updating the plan

When the itinerary changes, hand over the complete new version. The differences
against what's currently on the site get worked out, applied, and logged under
**Plan history** at the bottom of the page, with changed or added entries marked
`NEW` so they're easy to spot.

## Publishing it

To get a link you can open on your phone: repo **Settings → Pages → Source:
Deploy from a branch → `main` / root**. It'll be live at
`https://<username>.github.io/<repo>/` a minute later.
